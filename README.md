# ЦНАП Дорослого Життя

Мобільна HTML-гра на 60–75 хвилин: іронічний ЦНАП проводить вас через шість сфер життя (Гроші, Справа, Енергія, Люди, Місце, Сенс) і наприкінці видає «Витяг з Реєстру Наступного Етапу» — персональну карту на 90 днів, складену Claude.

## Як запустити

```bash
node build.js        # збирає dist/game.html (один самодостатній файл)
```

Потрібен лише Node.js 18+, залежностей немає.

**На телефоні** — будь-який з варіантів:
- GitHub Pages: Settings → Pages → Deploy from branch → `main` / root. Гра буде за адресою `https://<user>.github.io/Game-CNAP/` (кореневий `index.html` перенаправляє на `dist/game.html`).
- Надіслати собі `dist/game.html` і відкрити в браузері (Safari/Chrome).
- На комп'ютері: `cd dist && python3 -m http.server`, потім відкрити `http://<ip-комп'ютера>:8000/game.html` з телефона в тій самій мережі.

## Витяг

- **З ключем**: у фіналі вставте ключ Anthropic API — справа піде в Messages API (`claude-sonnet-5-5`), витяг з'явиться по ходу генерації. Ключ живе лише в пам'яті вкладки, нікуди не зберігається.
- **Без ключа**: «Скопіювати справу» → вставити в чат з Claude. У скопійованому тексті вже є повна інструкція.

## Структура

```
src/scenario.json   увесь сценарій: тексти, питання, варіанти, штампи, репліки, написи UI
src/prompt.js       особова справа + промт для AI (працює і в браузері, і в node — для майбутнього Telegram-бота)
src/api.js          стрімінговий запит до Anthropic API
src/md.js           безпечний рендер markdown
src/app.js          двигун гри та екрани; весь стан — один об'єкт state
src/styles.css      візуал: бланки, табло, печатки, темна тема
src/template.html   каркас сторінки
build.js            збирач + перевірка сценарію + оцінка тривалості
test/e2e.js         наскрізний тест у headless Chromium (потрібен Playwright)
docs/SPRINT_LOG.md  журнал спрінтів
```

## Як змінювати сценарій

Редагуйте `src/scenario.json` і запускайте `node build.js` — збирач перевірить структуру (6 віконець, 3 варіанти зі штампами, формулювання питання під кожен штамп) і покаже орієнтовний час проходження.

## Тест

```bash
node build.js && node test/e2e.js
```
